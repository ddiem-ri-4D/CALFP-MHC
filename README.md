# CALFP-MHC: Repurposing amino acid molecular fingerprints for supervised contrastive learning in MHC class I and II peptide binding prediction

This repository contains code and data to train [CALFP-MHC](https://github.com/ddiem-ri-4D/CALFP-MHC) model.

## Requirements

+ Python >= 3.6.8
+ Keras 2.6.0
+ TensorFlow 2.6.0
